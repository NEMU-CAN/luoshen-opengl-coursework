## 这一轮改了什么

水面是一整块四边形，顶点上的小起伏在画面里看不出来。这一轮把起伏画进水面颜色里，并在山坡中段加细的雾缕。

**水面。** 世界坐标上两道沿河的波：`sin(x * 0.85 + z * 0.45 + anim * 0.9)` 和 `sin(z * 1.7 - anim * 0.7)`。颜色在 `(0.12, 0.26, 0.34)` 和 `(0.62, 0.76, 0.82)` 之间拉开，主视图里近水会从大约 `(66, 88, 99)` 变到 `(152, 180, 191)`。`anim` 用 `sceneTime`，它为 0 时用 `cloudParams.x`。暖斑仍盖在这层动着的颜色上，中心大约 `(0.4, -2.2)`，最多混入 0.72 的 `(0.94, 0.62, 0.40)`。

**山坡雾缕。** 只在远处的蓝灰面上。高度大约从 0.2 到 6.5 的中段，`sin(worldHeight * 5.4)` 再过一道噪声，只留下较亮的一段，混入最多 0.78 的 `(0.83, 0.86, 0.85)`。峰顶不铺。主视图里是断在折面上的浅带，不是整座山发白。

**太阳和头发。** 没改。切边太阳大约 `(252, 220, 182)`。墨发大约 `(13, 8, 5)`。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 波的空间频率 0.85 和 1.7 | 水面上能看见起伏，不是圆 |
| 暖斑混入 0.72 | 暖色留在动着的水上 |
| 雾缕 `smoothstep(0.42, 0.8)` | 中坡的浅带，不是白雾 |
| 切边太阳和墨发未改 | 太阳浅桃，头发暗 |
