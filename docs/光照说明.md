# 光照说明（第二十二轮，未完成）

改了 `场景工程_美术重制/graphics_support.h`。`shadow_map.h` 没再改。

## 这一轮改了什么

上一轮的水面把颜色在深蓝和浅灰之间来回换，看起来是一块一块的。山坡上的雾是按高度画的细白线，横穿网格。这两处都去掉了。

**水面。** 底色固定在 `(0.30, 0.46, 0.54)`，起伏只加减大约 `0.02`，法线偏移大约 `0.08`。颜色不再被撕成深浅斑块。暖处是一个高斯，中心大约 `(0.2, -2.1)`，半径大约 4.6 和 2.8，最多混入 0.48 的 `(0.90, 0.58, 0.40)`。主视图里远水大约 `(87, 115, 129)`，暖处大约 `(154, 139, 131)`，再回到偏冷的灰蓝，中间是连续过渡。时间用 `sceneTime`，它为 0 时用 `cloudParams.x`，暖斑中心跟着慢慢挪一点。

**山谷雾。** 只在远处的蓝灰山上。高度从 1 到 5.6 平滑变淡，越靠近山脚越浓，最多混入 0.58 的 `(0.76, 0.82, 0.84)`。噪声只轻轻改变浓淡，不画线。主视图里峰顶仍是大约 `(46, 71, 74)`，山脚大约 `(135, 155, 159)`。

**太阳和头发。** 没改。切边太阳大约 `(252, 220, 182)`，切边和山脊之间仍有一段桃灰色的天。头发保持墨色。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 水面起伏 ±0.02 | 有一点动，颜色不碎 |
| 暖斑混入 0.48 | 太阳下面一块暖，不是长条 |
| 雾的高度 1 到 5.6 | 雾停在山谷和坡下，峰顶不白 |
| 切边太阳未改 | 浅桃圆盘，底边平切 |
