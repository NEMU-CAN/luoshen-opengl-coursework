# 洛水别绪：美术重制版

本项目用 C++ 与 OpenGL 构建《洛神赋》中相遇之后、即将分别的场景。曹植留在岸边，洛神独立水面回望，45 秒内渐渐远去。空舟放在远处。主景以两人之间的水面留白表达距离，深青与米白衣服区分人物，暖色天际与青绿水面构成暮色。

## 本轮重制

人物使用用户提供的Gemini辅助制作最终版：曹植3309三角面，洛神2861三角面（课程读取器）。洛神只做颈部与耳坠连接修复，保留原脸型、头发和服饰。旧MakeHuman及失败人物版本已移除，不属于当前来源。人物是文学场景的艺术化造型，不是历史服饰精确复原。

山体是三层有深度的起伏网格，岸线由连续曲线控制，树石按疏密分组，草地按不规则区域生长。暖天空、距离雾和高度雾降低远景对比。右上角使用小题款；操作帮助按 H 显示。

## 课程图形学实现

OBJ 读取器支持独立位置/UV/法线索引、负索引、多材质、map_Kd 和 map_d。素材预先三角化，读取器的扇形剖分仅适用于凸面。落脚包围盒只统计实际参与三角形的顶点，排除人物未使用的辅助顶点。

纹理由 Windows WIC 读取，保留 UV，采用 mipmap 和线性过滤；树叶与眉睫使用 alpha 裁切。模型数据上传 VBO，一份模型可重复摆放。地面使用颜色图与切线空间法线图，通过位置和 UV 的屏幕导数建立切线框架。

GLSL 1.20 顶点着色器完成位置、法线变换与局部衣带/草地位移；片元着色器实现 Phong 的环境项、漫反射项与镜面项。光源世界位置为 (-12,16,9)，环境项为 (0.31,0.36,0.39)，主光为 (0.88,0.70,0.49)，另加弱冷色补光。普通材质高光指数 35，水面 105，头发 70。参数是美术选择，不是实测物理参数。

`shadow_map.h` 建立 2048×2048 深度纹理与仅深度 FBO，先从光源视角绘制树石舟和人物，再将眼空间坐标转换到阴影坐标。alpha 裁切和衣带位移在两次绘制中保持一致。四次硬件过滤的深度比较柔化边缘，法线相关 bias 与多边形偏移降低自阴影伪影。阴影只衰减主光，保留环境光和补光。阴影区域有限，不是全场景任意距离的阴影系统。

水面先写模板，树与人物镜像几何受模板限制。倒影按深度横向扰动并透明衰减，水面以 0.86 alpha 覆盖。法线扰动、细碎金色波光和弱的不完整涟漪由周期函数生成。这是水平面镜像与程序水纹，没有流体求解或完整环境反射。

## 动画与交互

三次 Bézier 曲线 B(u)=(1-u)^3 P0+3(1-u)^2u P1+3(1-u)u^2 P2+u^3 P3，控制点为 (1,0.045,-1.2)、(1.2,0.045,-2.2)、(2.8,0.045,-3.7)、(4.5,0.045,-4)。时间 t=clamp(T/45,0,1)，再以 u=t²(3-2t) 平滑起止；不是匀速弧长参数化。洛神到终点停留，衣带、水纹和空船仍轻动。

空格暂停统一动画时间；R 清零时间、恢复播放和主视角。鼠标旋转/平移、滚轮缩放、WASD及四个预设视角可观察场景；P显示路线，F9保存BMP。人物OBJ是摆好姿势的静态网格，C++没有骨骼蒙皮、表情、行走或真实布料模拟。可编辑Blender文件位于根目录assets的两个current目录。

## 验证与边界

当前构图新增花枝、岩岸、舟篷、松树、远岸5个OBJ，协作仓库包含15个OBJ；本地若保留3艘备用舟则共18个。检查入口为根目录scripts/check.ps1。树石会重复绘制，另有倒影、阴影和程序地形，文件面数不能当作每帧总三角形数。读取测试覆盖UV、法线、负索引、透明图、错误输入、落脚点计算及曲线端点、中点和钳制。

六张展示图来自实际 C++ 帧缓冲，覆盖主景、全景、人物近景、22.5 秒及 45 秒。不是概念图。程序回调检查包含旋转、缩放、暂停与暂停后重播；不等同于在所有硬件上完成人工输入验收。

最终人物替换后的帧率应在目标电脑重新实测；早期约41FPS的数据不作为当前版本保证。降低开销可先检查重复树木、倒影绘制与阴影分辨率，再对照视觉效果。

人物面部、手指、衣褶和草地重复感仍有精细度限制；远山为艺术化简化地形。当前方向适合课程实时场景，不是电影级人物动画。报告需按老师模板整理，小组分工由小组填写，视频由用户自行录制。本包没有 MP4 或录屏功能。
