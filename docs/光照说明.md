# 光照说明（第十九轮，未完成）

改了 `场景工程_美术重制/graphics_support.h`。`shadow_map.h` 仍把帧时钟放在 `cloudParams.x`。没有改模型，也没有改 `main.cpp`。

## 这一轮改了什么

上一轮的波纹加在光照之前，乘完之后几乎看不见。远处也不再铺白雾，山谷里只留一层很浅的雾。

**波纹。** 光照之后再画。洛神用每帧的 `goddessPosition.xz`，船用 `(-2, -6.9)`。半径 `sin(radius * 7.5 - anim * 2.3)`，亮环混到 `(0.93, 0.96, 0.98)`，暗环压到大约 0.45。时间用 `sceneTime`，它为 0 时用 `cloudParams.x` 里的帧时钟。人和船的位置一变，环就跟着走。

**暖斑。** 中心在 `(0.4, -2.2)` 附近，随时间小幅偏移，横向 2.2、纵向 1.3。环画完后再混入 0.62 的 `(0.96, 0.64, 0.42)`，所以暖色留在水面上，不是一条长痕。其余的水仍是蓝灰。

**山和雾。** 远的蓝灰面仍按法线受光：环境光 `(0.32, 0.36, 0.40)`，主光 `(0.78, 0.62, 0.48)`。只有这些面、而且 `worldHeight` 在 0.4 到 3.2 之间，才混入最多 0.22 的 `(0.70, 0.78, 0.82)`。峰顶不铺。空气混合上限仍是 0.02。主视图山峰大约 `(132, 153, 149)`，坡面大约 `(46, 67, 69)`，不是白的。

**人和地。** 地面主光 `(0.72, 0.62, 0.48)`。人物主光 `(0.64, 0.58, 0.52)`。墨发仍走暗的一支，发髻大约 `(13, 8, 5)`。

**太阳。** 没改。`normalize(-0.12, 0.16, -1)`，下切 `step(below, 0.012)`。圆盘大约 `(252, 219, 182)`，在山脊上方。
