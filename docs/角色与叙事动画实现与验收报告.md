# 《洛水别绪》角色与叙事动画实现与验收报告

## 1. 任务概述

角色与叙事动画模块在 `main` 静态场景的基础上完成三件事：

1. **洛神离去**：用三次 Bézier 曲线组织路线，安排起步前的停顿、逐渐离开和结尾停留，交付控制点、时间到曲线参数的映射、位置与朝向。
2. **披帛轻摆**：核对披帛在现有模型中的可识别范围，肩边固定、中段轻摆、末端摆幅更大且相位稍晚，形成由根到梢的波动；只对披帛顶点做局部变形，不改造型和材质。
3. **小舟微动**：以当前泊位为基准做轻微起伏和摆动，保持船底贴水、船身不穿岸。

同时提供约 45 秒演示的分段说明，并验证暂停、重置、播放到末尾后稳定停留。

可见结果：

- 洛神在 0–4 秒静立回望，4–34 秒沿曲线转身离去，34–45 秒停在终点；主镜头下人物高度缩小到约四分之三，同时明显向右移动。
- 披帛（红色飘带、金色披帛、四层玉色/象牙色垂纱）逐顶点变形，肩部固定，末端摆幅约为中段的 1.5–2 倍，相位滞后形成行波。
- 小舟升沉、横摇、纵摇、艏摇四个自由度微动，四个周期互质，0 秒与泊位完全重合。
- 提供 45 秒、30 fps、1600×900 的演示视频；11 个时间点的分段截图；披帛与小舟的近景对照图。
- 新增自动测试，覆盖路径端点、连续性、岸线/小舟避让、披帛根部固定与行波、小舟幅度与静止基准。

## 3. 洛神沿 Bézier 曲线离去

### 3.1 控制点与路线

三次 Bézier 曲线：

```text
B(t) = (1-t)³P0 + 3(1-t)²tP1 + 3(1-t)t²P2 + t³P3
```

| 控制点 | 坐标 | 说明 |
|---|---|---|
| P0 | `(1.000, 0.045, -1.200)` | 与 `scene_layout::luoshenPosition` 一致，起点不跳变 |
| P1 | `(2.300, 0.045, -1.700)` | 先向画面右侧展开，让位移在镜头里可见 |
| P2 | `(3.400, 0.045, -2.450)` | 继续向右前方，只略微后退 |
| P3 | `(4.450, 0.045, -2.800)` | 右前方开阔水面，仍在画面内，右岸线之外 |

曲线长度约 3.81 世界单位。主镜头（yaw −3°、pitch 5°、距离 6.7）下，起点屏幕坐标约 `(993, 751)`，终点约 `(1450, 654)`，人物在画面中从约 677 像素高缩小到约 513 像素：横向位移明确，同时保留一点远去感。

### 3.2 时间到曲线参数

若直接把 `smootherstep(t/45)` 当作曲线参数，两端速度虽然为 0，但中段起步极慢：45 秒演示的前十多秒几乎看不到位移。本次改为对速度曲线积分：

```text
u = clamp((秒数 - 4) / 30, 0, 1)
v(u)：u∈[0,0.12] 平滑加速，u∈[0.12,0.82] 匀速，u∈[0.82,1] 平滑减速
曲线参数 t = ∫₀ᵘ v du / ∫₀¹ v du
```

归一化后，中段速度基本恒定；实测最大速度约 `0.162` 世界单位/秒（起步后 8 秒前后），平均约 `0.127`。各时间点参数：

| 时间 | 曲线参数 | 位置 (x, z) | 速度 |
|---|---|---|---|
| 4 s | 0.000 | (1.00, −1.20) | 0 |
| 8 s | 0.086 | (1.33, −1.33) | 0.162 |
| 13 s | 0.282 | (2.06, −1.67) | 0.157 |
| 18 s | 0.478 | (2.74, −2.02) | 0.151 |
| 23 s | 0.675 | (3.40, −2.35) | 0.144 |
| 28 s | 0.871 | (4.04, −2.65) | 0.136 |
| 33 s | 0.999 | (4.45, −2.80) | 0.012 |
| 34–45 s | 1.000 | (4.45, −2.80) | 0 |

### 3.3 位置与朝向

模型默认面向 `+Z`，静态站位 `yaw = −25°`。离去时朝向与曲线参数同步插值到 `108°`：

```text
yaw(t) = −25° + 133° · t
```

观众先看到洛神回望，随后她缓慢转身、朝右前方走去；朝向始终跟着位移推进，不会停在原地打转。由于朝向与位移共用同一条缓动曲线，起步、停止时角速度为 0；0.01 秒采样下最大角度步进约 0.052°，位置步进约 0.0016 世界单位，均无跳变。

### 3.4 路线约束

自动测试沿整条曲线以 0.05 秒采样 901 个点，逐点检查：

- `x ≥ shoreline(z) + 0.55`：不进入左岸；
- `x < 8.0`：不进入右岸与远景山体；
- 与小舟水平距离 `> 1.2`：不穿过小舟；
- `0.03 ≤ y ≤ 0.06`：贴水面移动，不浮空也不入水。

全部通过。

## 4. 披帛轻摆

### 4.1 披帛的识别范围

从 `luoshen.obj` 的材质批次中确认了披帛相关网格：`Wind_GoldPibo`（金色披帛，576 三角形，包围盒 x −0.499…0.048、y 0.985…1.403）、`Wind_RedRibbon` / `Wind_RedEdge`（红色飘带与红边，共 1048 三角形，向 −X 延伸到 −1.133）、`Drape_JadeSilk` / `Drape_IvorySilk` / `Drape_IvorySilkBack` / `Drape_IvorySilkMid`（四层垂纱，共 12712 三角形）。这些批次在 `main.cpp` 中已有独立 `kind`，因此可以单独识别和变形。

### 4.2 变形场

披帛变形模块 `pibo_motion.h` 对每个顶点计算：

```text
s      = 根部到末端的归一化参数 ∈ [0,1]
w(s)   = 摆幅权重，w(0)=0，随 s 增大
φ(s,t) = 1.08t − λ(s)            （λ 随 s 增大，末端相位更晚）
offset = A · w(s) · [ D sinφ + L sin(0.61φ+1.2) + U sin(φ+0.55) ]
```

参数化方式：

| kind | 材质 | s 的定义 | 基础摆幅 A |
|---|---|---|---|
| 8 | 红飘带/红边 | `s = (−0.033 − x) / 1.10` | 0.052 |
| 9 | 金色披帛 | `s = (1.403 − y) / 0.418` | 0.024 |
| 26 | 玉色垂纱 | `s = (0.88 − uv.v) / 0.75` | 0.060 |
| 27 | 象牙色垂纱 | 同上 | 0.052 |
| 28 | 背层垂纱 | 同上 | 0.046 |
| 29 | 中层垂纱 | 同上 | 0.050 |

权重函数在根部严格为 0，保证肩边接缝不动；kind 8 用 `s^1.55`，kind 9 用平滑阶跃的 1.15 次方，四层垂纱用 `s²(0.55+0.9·free)`，末端额外增加摆幅。相位滞后 kind 8 为 `6.2s`，kind 9 为 `4.0s`，垂纱为 `5.4s + 0.32(kind−26)`。

### 4.3 与着色器的分工

主分支里披帛原本由顶点着色器的 `materialKind==8/9/26..29` 分支做位移。本次在这几类批次上把 `clothMotionEnabled` 置 0，位移完全交给 `pibo_motion.h`，避免两层摆幅叠加；袖子、裙摆等其他布料仍走原有着色器分支。`graphics_support.h` 没有改动。

### 4.4 写回与一致性

`updatePiboDeformation()` 每帧从保存的静止顶点出发，计算位移后写回对应 VBO（约 4.5 万顶点、约 1.4 MB）。阴影、水面倒影和正片共用同一份 VBO，因此三处姿态天然一致。顶点法线保持静止值，与原先着色器位移的做法相同；摆幅小于 16 cm，明暗不会出现明显跳变。

### 4.5 验收观察

`docs/narrative-animation/02-pibo-compare.png` 是同一时刻（t=18 s）披帛变形开启与静止对照的近景裁剪；`03-pibo-closeup.png` 是 t=0 与 t=8 s 的独立特写。可以看到：

- 肩部接缝位置不动，披帛没有脱肩；
- 中段只有小幅摆动，末端（红飘带末端、垂纱下摆）摆幅明显更大；
- 末端峰值晚于中段，形成从肩到梢的传播；
- 没有穿身、穿岸或折面被拉坏的情况。

## 5. 小舟微动

小舟以布局泊位 `(-3.24, 0.025, -8.29)` 为基准，叠加四个自由度：

```text
heave = 0.018 sin(0.72t) + 0.006 sin(0.33t)     // 升沉，最大 2.4 cm
roll  = 1.05° sin(0.55t)                         // 横摇
pitch = 0.55° sin(0.81t)                         // 纵摇
yaw   = 0.45° sin(0.47t)                         // 艏摇
```

四个周期分别约 8.7 s、11.4 s、7.8 s、13.4 s，互不同步，避免机械感；`t=0` 时四项全部为 0，重置后与 `scene-layout.txt` 中的泊位完全一致。

按船体 18.9 千个顶点逐帧计算，船底最低点相对水面的范围为 `−4.2 cm … +3.6 cm`，约为 2.05 m 船体高度的 2%，视觉上保持“船底贴水”。转动中心在船底中心，横摇 1.05° 时船身横向位移小于 4 cm，不会穿入左岸。主镜头中小舟只占约 200 像素宽，运动幅度刻意保持克制，以维持离别场面的安静感；近景对照见 `04-boat-compare.png`。

## 6. 主程序接入

### 6.1 统一时钟

沿用主程序已有的 `animationTime`。每帧：

```cpp
if (animationPlaying) animationTime += dt;
const auto farewell = scene_motion::farewell(animationTime);
const auto boatMotion = scene_motion::boatMotion(animationTime);
const float wind = scene_motion::windEnvelope(animationTime) * clothStrength;
updatePiboDeformation(luoshen, animationTime, wind);
```

洛神、披帛、小舟都只读取这一个时间，没有第二个计时器。

### 6.2 姿态替换

`drawEditable` 在绘制洛神时用 `farewell.position / farewell.yaw` 替换静态 `pose`；绘制小舟时在 `position.y` 叠加 `heave`、在 `yaw` 上叠加艏摇，并把 `pitch / roll` 传给 `drawModel` 的 `tilt` 参数。阴影、倒影、正片和披帛半透明层共用该姿态。进入 Tab 摆放模式时恢复静态姿态，避免摆放被动画干扰。

### 6.3 暂停、重置与结束

- 空格：停止 `animationTime` 累加，洛神、披帛、小舟同时冻结。
- R：`animationTime = 0`，洛神回到起点、披帛风场为 0（静止形态）、小舟回到泊位，同时恢复主镜头。
- 播放到 45 秒后：`farewell()` 对时间夹紧，位置和朝向精确停在 P3 / 108°；小舟和披帛继续以安静幅度微动。

### 6.4 相机与截图入口

按 3 号镜头时目标点跟随洛神当前位置。新增以下命令行入口，便于脱离交互单独验收：

| 命令 | 内容 |
|---|---|
| `--capture-farewell` | 45 秒中 11 个时间点，`captures/farewell/` |
| `--capture-farewell-still` | 同一时间点、披帛静止的对照，`captures/farewell-still/` |
| `--capture-pibo` | 披帛近景 7 帧，`captures/pibo/` |
| `--capture-boat` | 小舟近景 8 帧，`captures/boat/` |
| `--capture-farewell-video [帧数]` | 30 fps 连续帧，默认 1350 帧，`captures/farewell-video/` |

## 11. 协作与合并说明

- 核心逻辑集中在 `scene_motion.h` 与新增的 `pibo_motion.h`；`main.cpp` 只加入必要的统一时钟、姿态替换、VBO 更新、截图模式和自检，符合“主程序由布局负责人统一接入”的约定。
- 没有修改布局、光照、阴影和环境动态模块。披帛批次的着色器位移被关闭，是为了避免与 CPU 变形叠加；合并时如果光照负责人也要调整这几类批次的着色器分支，请保留 `clothMotionEnabled == 0` 的约定，或改为由同一套风场参数驱动，避免两层位移。
- 披帛变形每帧只更新披帛批次，其他模型和纹理资源不重建。
- 若布局负责人调整了洛神或小舟的静态泊位，需要同步修改 `scene_motion.h` 中的 `kP0` 与 `kEndYaw` 起点，并更新 `mesh_tests.cpp` 的起点断言；小舟的基准位置直接读取布局，不需要改代码。

## 12. 已知限制与后续可做

- 人物是静态网格，转身表现为整体绕 Y 轴旋转，没有步态或手臂摆动；这是现有资产的限制，当前实现只做路线、朝向、披帛和小舟。
