# 面纱飘动

只改 `graphics_support.h` 中 `materialKind==19` 的顶点位移分支，未动模型、UV、材质、镜头与其它衣料。

## 原来的问题

旧代码的固定权重是 `sin(π·uv.x)·uv.y²`：两侧边缘也被一起钉死，整块纱只能做极小的整体抖动（z 向最大 0.011），看起来像硬片微颤。

## 现在的做法

- **只固定额前那条边**。`uv.y=0` 对应 y=1.522 的额前固定线，用 `smoothstep(0,.30,uv.y)²` 作权重，左右两侧放开，下摆可自由飘。
- **位移只朝外侧**：`z` 方向只做 `+0.006 ~ +0.013`，永远远离脸，不会穿到脸前。
- 两组不同频率的行波叠加（`slow` 沿横向传播、`echo` 带 1.37 倍频），避免整片同相抖动。周期 5 秒（60fps）。
- 保留 `smoothstep(0,.9,clothTime)` 包络：按 `0` 回静止时位移严格为 0，`Cloth callbacks ... rest PASS` 未被破坏。

## 实测

| 指标 | 结果 |
|---|---|
| 面纱屏幕包围盒 | (1105,151)–(1214,261)，约 110×110 px |
| 该区域帧间变化 | 最大 6.59（mean abs diff） |
| 远处对照区域 | **0.000**（完全无变化） |
| 100 个相位内与脸/鬓发/脖颈最近距离 | 0.00176，且**最小值出现在 t=0 静止姿态** |
| 额前固定边位移 | 严格 0 |
| 峰值横向 / 外移 | 0.015 / 0.013 模型单位 |

即：动画从未比原始静止状态更贴近脸；额前边一点没动；变化只发生在面纱所在区域。

`scripts/check.ps1 -Capture` 全 PASS，四视角 `GL error=0`。
