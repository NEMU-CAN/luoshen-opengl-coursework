# 光照说明（第六轮，未完成）

只改 `场景工程_美术重制/graphics_support.h` 和 `shadow_map.h`。人物位置和 `main.cpp` 里的天空、光源上传都没动。目标仍是参考图：桃杏色的天、淡太阳、蓝灰水面、冷雾里的远山、人物身上柔和的暖光。水面不能发红。

## 这一轮改了什么

主光再收软，暗部再偏冷，日影收成一条细线。折面靠法线的明暗分开，阴影贴图不再在脸上留下脏斑。

**太阳位置没变。** 主程序仍上传 `(-12, 16, 9)`，着色器沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`。阴影相机看向 `(-4.2, 0.5, -2.8)`。

**人物和石头。** 环境光改成偏暖的暗部 `(0.26, 0.20, 0.18)`，主光 `(0.68, 0.40, 0.18)`。正对光大约是 `(0.94, 0.60, 0.36)`，是夕阳，不是冷灰。漫反射用 75% 的原始 `N·L` 加上 25% 的 `smoothstep(0.08, 0.82)`，折面还在，脸不会被压成两块平色。补光只剩 `(0.04, 0.05, 0.07)`。朝上面加 `(0.08, 0.045, 0.02)`，轮廓边光 `(0.10, 0.055, 0.03)`。影子里仍留 55% 直射，暗部大约 `(0.63, 0.42, 0.28)`，暖，但不黑。

**高光。** 皮肤和石头指数 22、强度 0.010，颜色 `(1.0, 0.88, 0.76)`。头发指数 40、强度 0.035。水面指数 150、强度 0.03，颜色 `(1.0, 0.94, 0.82)`，只在波峰上一点淡桃。

**水面。** 本体仍是蓝灰：`(0.18, 0.32, 0.38)` 混到 `(0.40, 0.54, 0.60)`。水面光照是冷的 `(0.64, 0.72, 0.76)`，不乘暖主光。日影带宽度从 0.14 收到 0.07，颜色只加 `(0.18, 0.11, 0.06)`。人物倒影只混 0.07 的 `(0.84, 0.70, 0.58)`。

**远山和雾。** 山体仍用冷色 `(0.60, 0.66, 0.74)`，远处雾上限 0.16、雾色 `(0.46, 0.54, 0.60)`，峰顶保持蓝灰。山腰和山脚另有一层雾：以世界高度 1.3 为中心、宽度 1.7，再乘一点大尺度噪声，最多混入 0.50 的 `(0.66, 0.75, 0.82)`。高度到 5 以上几乎没有这层，所以不会再铺成雪。水面本体不变。

**天空里的云。** 上一轮用 `atan(x, z)`，方位角在正负 180° 对切的地方会裂开一条竖缝，高频噪声又把云切成碎块。现在不用方位角。视线的 `yz` 和 `xy` 各采一次低频噪声，按 `rd.x²` 和 `rd.z²` 混合，转一圈都连续。尺度 2.4，阈值 `smoothstep(0.43, 0.55)`，只要少数整朵软云，颜色 `(0.98, 0.91, 0.82)` 到 `(1.0, 0.97, 0.94)`，透明度最多 0.48。云仍跟着世界视线走，转相机时会在天上挪动，不粘在屏幕上。地平线薄雾跟 `rd.y`，中心 0.07、宽度 0.055，颜色 `(0.72, 0.80, 0.86)`，透明度 0.26。花瓣模块没有动。

**阴影。** 最暗保留 55% 直射光：`visibility = 0.55 + 0.45 * 四次采样平均`。脸上的影子大约是 `(0.63, 0.42, 0.28)`，比受光面暗，仍是暖的。采样大约 8 个纹素宽。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。范围仍是正交 ±13，近 0.2、远 64。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 太阳 `(-12, 5.5, 9)`，下移 `-10.5` | 和阴影相机是同一个点 |
| 环境光 `(0.26, 0.20, 0.18)`，主光 `(0.68, 0.40, 0.18)` | 人物和石头是暖夕阳 |
| 云用 `rd.yz` 与 `rd.xy` 混合，尺度 2.4，阈值 0.43–0.55 | 没有竖缝，云是整朵，转相机会动 |
| 山雾中心高度 1.3，宽度 1.7，最多 0.50 | 雾在山脚和山腰，峰顶仍是蓝灰 |

天空圆盘仍在 `main.cpp`。这一轮没有改它。
