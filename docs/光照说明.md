# 光照说明（第十八轮，未完成）

改了 `场景工程_美术重制/graphics_support.h` 和 `shadow_map.h`。没有改模型和 `main.cpp`。太阳仍是浅桃色切边圆盘。头发仍是墨色。

## 这一轮改了什么

上一轮把远处的蓝灰面混进最多 0.58 的白雾，山和远地发白，折面几乎看不出受光。水面的时间和圆心也不跟着人或船走。

**雾。** 去掉那层白雾。空气混合上限改为 0.02，雾色不再接近白色。山保持蓝灰，远地不再被涂白。

**受光。** 山的环境光大约 `(0.32, 0.36, 0.40)`，主光 `(0.78, 0.62, 0.48)`，漫反射以 `N·L` 为主。地面环境光 `(0.38, 0.36, 0.32)`，主光 `(0.72, 0.62, 0.48)`。人物环境光 `(0.40, 0.38, 0.36)`，主光 `(0.64, 0.58, 0.52)`。没有贴图而且很暗的颜色（墨发）用更低的光，发髻大约 `(10, 6, 4)`，不会被抬成白色。

**太阳。** 没改：`normalize(-0.12, 0.16, -1)`，下切 `step(below, 0.012)`。主视图圆盘大约 `(252, 220, 182)`，仍在山脊上方。

**水面。** 着色器读 `sceneTime`。主程序在天空之后把这个值写成 0，所以天空那一趟把 `glfwGetTime()` 放进 `cloudParams.x`。`sceneTime` 大于 0 时用水的是它，否则用这一帧的时钟，不另做一套计时。暖斑中心在 `(-1.4, -5.2)` 附近，按时间做小幅偏移：`sin(anim * 0.35) * 0.55` 和 `cos(anim * 0.27) * 0.35`，仍是一块，不是长条。波纹有两处。洛神用每帧上传的 `goddessPosition.xz`。船用布局里的 `(-2, -6.9)`。两处都随同一个时间向外扩。

**阴影。** `visibility = 0.55 + 0.45 * 四次采样平均`。采样大约 8 个纹素宽。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。

## 哪些数最要紧
