# 光照说明（第五轮，未完成）

只改 `场景工程_美术重制/graphics_support.h` 和 `shadow_map.h`。人物位置和 `main.cpp` 里的天空、光源上传都没动。目标仍是参考图：桃杏色的天、淡太阳、蓝灰水面、冷雾里的远山、人物身上柔和的暖光。水面不能发红。

## 这一轮改了什么

主光再收软，暗部再偏冷，日影收成一条细线。折面靠法线的明暗分开，阴影贴图不再在脸上留下脏斑。

**太阳位置没变。** 主程序仍上传 `(-12, 16, 9)`，着色器沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`。阴影相机看向 `(-4.2, 0.5, -2.8)`。

**人物和石头。** 环境光 `(0.24, 0.32, 0.40)`，主光 `(0.40, 0.26, 0.15)`。正对光大约是 `(0.64, 0.58, 0.55)`，暖，但比上一轮更淡。背光只剩环境光，是清楚的冷蓝灰，不是黑，也不是脏褐色。补光 `(0.03, 0.06, 0.11)`。朝上一面再加一层很淡的暖光 `(0.05, 0.035, 0.02)`。轮廓有一圈淡桃边光，指数 2.6，颜色 `(0.07, 0.04, 0.028)`，只勾出形体，不把脸照白。漫反射先做 `smoothstep(0.08, 0.82, N·L)`，低模的大平面还能分开，过渡不那么硬。

**高光。** 皮肤和石头指数 22、强度 0.010，颜色 `(1.0, 0.88, 0.76)`。头发指数 40、强度 0.035。水面指数 150、强度 0.03，颜色 `(1.0, 0.94, 0.82)`，只在波峰上一点淡桃。

**水面。** 本体仍是蓝灰：`(0.18, 0.32, 0.38)` 混到 `(0.40, 0.54, 0.60)`。水面光照是冷的 `(0.64, 0.72, 0.76)`，不乘暖主光。日影带宽度从 0.14 收到 0.07，颜色只加 `(0.18, 0.11, 0.06)`。人物倒影只混 0.07 的 `(0.84, 0.70, 0.58)`。

**远山和雾。** 上一轮把远山混进很亮的 `(0.76, 0.82, 0.87)`，上限 0.58，山坡看起来像雪。现在冷色系数仍是 `(0.60, 0.66, 0.74)`，远山雾浓度降到 0.008，上限 0.16，雾色改成 `(0.46, 0.54, 0.60)`，只略淡一点，山体保持蓝灰。山脚只留一条薄雾：世界高度除以 0.7 再做高斯，最多混入 0.22 的 `(0.52, 0.62, 0.68)`，不往坡上铺白。近处的人和水面几乎不进雾：起点仍是 10，水面浓度 0.005，其他景物 0.007，上限 0.24。

**天空里的云。** 不新建模型。全屏片元（`materialKind == 8`）仍盖在已画好的天空上，不写深度。云不再用屏幕坐标做噪声。每个像素用相机的右、上、后方向，把屏幕点还原成世界视线（半视角的正切是 0.4142，对应 45° 视角）。噪声坐标是视线的方位角 `atan(x, z)` 和高度 `y`。相机一转，同一块云就离开原来的屏幕位置，留在天空里。噪声在方位角上大约每 1.8 弧度一格，所以主镜头里能看见几团，而不是一整片渐变。阈值 `smoothstep(0.55, 0.72)`，颜色 `(0.98, 0.90, 0.80)` 到 `(1.0, 0.97, 0.93)`，透明度最多 0.62。地平线雾跟世界高度走：`rd.y` 在 0.06 附近、宽度 0.05，颜色 `(0.70, 0.78, 0.84)`，透明度 0.28。花瓣模块没有动。

**阴影。** 最暗保留 55% 直射光：`visibility = 0.55 + 0.45 * 四次采样平均`。脸上的影子大约是 `(0.46, 0.46, 0.49)`，冷，不脏。折面的亮暗主要来自法线，不靠把影子压黑。采样大约 8 个纹素宽（`offset * 8 / 2048`）。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。范围仍是正交 ±13，近 0.2、远 64。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 太阳 `(-12, 5.5, 9)`，下移 `-10.5` | 和阴影相机是同一个点 |
| 环境光 `(0.24, 0.32, 0.40)`，主光 `(0.40, 0.26, 0.15)` | 受光淡暖，暗部冷 |
| `smoothstep(0.08, 0.82, N·L)` | 折面可读，又不黑成一块 |
| 阴影下限 0.55，采样约 8 纹素 | 岩岸有软影子，脸不脏 |
| 日影宽度 0.07，倒影桃色混合 0.07 | 桃只剩细的一层 |
| 云用 `atan(rd.x, rd.z)*1.8` 和 `rd.y*7`，阈值 0.55–0.72 | 云钉在世界天空里，转相机会挪开 |
| 远山雾上限 0.16，山脚高度 0.7 | 山保持蓝灰，雾只在山脚和地平线 |

天空圆盘仍在 `main.cpp`。这一轮没有改它。
