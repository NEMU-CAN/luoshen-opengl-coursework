# 洛水别绪使用说明

这是用 C++ 与 OpenGL 实现的《洛神赋》河岸离别场景。曹植留在岸边，洛神独立立于水面，回望并在 45 秒内缓缓远去。远处小舟为空船。

## 先运行

双击本目录的 `打开场景.cmd`。保留 `bin`、`assets` 和目录层级。程序首次读取树木和人物需要几秒。运行需要 Windows 10 或 11 的 x64 系统和支持 OpenGL 2.1、深度纹理及 Framebuffer Object 的显卡驱动；运行程序不需要 Blender 或 Visual Studio。

需要单独检查水面花瓣、桃树落花、波光和涟漪时，双击同目录的 `演示环境动态.cmd`；该模式会隐藏两个人物并使用环境观察镜头，空格暂停和 R 重置仍然有效。

| 操作 | 效果 |
|---|---|
| 左键拖动 | 围绕观察中心旋转 |
| 右键拖动 | 平移观察中心 |
| 滚轮 | 缩放 |
| W A S D | 移动观察中心 |
| 1 | 主视角 |
| 2 | 场景全景 |
| 3 | 洛神近景，按键时对准她当前的位置 |
| 4 | 曹植近景 |
| 空格 | 暂停或继续全部时间驱动的动画 |
| R | 从头重播并恢复主视角，暂停时也能重新播放 |
| P | 显示或隐藏人物位置与 Bézier 运动路径 |
| H | 显示或隐藏底部操作提示，右上角保留小题款 |
| F9 | 将当前画面保存到 `bin/screenshot.bmp` |
| Esc | 退出 |

洛神到达终点后停留，水面和衣带继续轻动；再次观看离别过程请按 R。程序没有录屏或 MP4 导出功能，视频由使用者自行录制。

## 用 Visual Studio 修改

打开 `LuoshenScene.vcxproj`，选择 Release 和 x64，生成后按 Ctrl+F5 运行。需安装 C++ 桌面开发与 Windows SDK。工程当前工具集为 v145；若组员使用 VS 2022，可在项目属性中把平台工具集切换为已安装的 v143。保留 C++17、UTF-8 编译选项及附带的 third_party。

| 想修改什么 | 从哪里开始 |
|---|---|
| 人物、船、树和岩石的位置 | `main.cpp` 主循环中的 `drawModel` 调用 |
| 模型的大小和朝向 | `drawModel` 的角度、缩放参数，坐标采用 Y 轴向上 |
| 主视角 | `main.cpp` 的 `resetView` |
| 光源位置 | `main.cpp` 中 `glm::vec4(-12,16,9,1)，阴影光源同时见 shadow_map.h` |
| 光照、雾、水纹和法线贴图强度 | `graphics_support.h` 的片元着色器 |
| 洛神的运动路线、45 秒时长 | `scene_motion.h` 中四个控制点与时间计算 |
| 标题和操作文字 | `scene_overlay.h` |
| 服装和人物形状 | 用Blender打开根目录assets下两个current目录中的工程，导出OBJ/MTL后同步运行素材 |
| 图片花纹与配色 | `assets/luoshen-characters` 的 textures 图片及对应 MTL；UV 需要保留 |

`drawModel(model, view, position, angle, scale)` 中 position 是落脚点，angle 是绕 Y 轴的角度，scale 是统一缩放。程序会先把原模型的水平包围盒中心与底部移到原点，再摆放到场景。可先改一个参数、生成运行观察，再继续改。

## 验证入口

使用根目录 `scripts/build.ps1` 和 `scripts/check.ps1` 构建并检查OBJ/MTL、贴图和路径数学；仓库排除备用舟，当前提交15个OBJ。`bin/LuoshenScene.exe --capture`隐藏窗口输出6张实际程序截图；`--smoke`隐藏窗口预热后运行约6秒并打印显卡错误与短时帧率。这两项不录制桌面。

源码使用 GLSL 1.20 兼容上下文，模型几何由 VBO 缓存，地面和少量辅助几何仍采用兼容绘制接口。它不是 OpenGL 核心模式工程。若教师另有核心模式或指定框架要求，需要按课程约定调整。

阴影实现见 `shadow_map.h`：2048 深度纹理与硬件比较过滤。阴影有/无对照可用 `--capture-no-shadows`，该选项会覆盖 bin/captures 中的检查图；通常使用 `--capture` 还原正常图。右上角题款默认显示，H 切换底部操作帮助。
