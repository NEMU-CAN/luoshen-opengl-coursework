# 环境动态设计说明

## 目标与边界

环境模块只负责水面花瓣、桃树落花和水面动态，不改变人物路线、镜头或场景布局。所有效果读取主程序唯一的 `animationTime`；空格暂停后姿态保持不变，R 重置后回到同一初始状态。

## 数学模型

- 水面花瓣共 48 个，其中 34 个沿左岸分布，14 个稀疏分布在右侧开阔水面。每个花瓣由固定种子生成基础位置，叠加低频正弦位移：X 方向最大 0.10，Z 方向最大 0.18，避免画面抖动。
- 岸线使用与主场景一致的三项正弦函数。花瓣与岸线保持至少 0.32 的水面间距，并分别避开洛神 0.78、小舟 1.05 的水平半径。
- 主镜头中央使用椭圆留白：中心 `(-0.35, -4.4)`，X/Z 半轴为 `1.25/3.15`。该区域不绘制水面花瓣，保证人物之间的叙事空间不被填满。
- 空中花瓣共 14 个。每片使用 7.5 至 11 秒的独立周期，从桃树冠下落；水平摆动、偏航和翻滚均由连续正弦函数计算。周期相位由固定种子错开，因此重播结果可复现。
- 水面法线、波光和洛神脚边同心涟漪继续由 `graphics_support.h` 的水材质计算。本轮只把原先固定为 0 的 `sceneTime` 接到共享时钟，不改共享光照片元代码。

## 接口与接入位置

纯计算接口位于 `environment_effects.h`：

- `waterPetalPose(index, seconds)`：返回水面花瓣的位置、朝向、缩放和倾斜。
- `visibleWaterPetal(pose, goddess, boat)`：执行岸线、人物、小舟和中央留白避让。
- `fallingPetalPose(index, seconds, blossom)`：返回桃树落花姿态。
- `drawWaterPetals(...)` 与 `drawFallingPetals(...)`：在主场景不透明物体绘制完成后调用。

`main.cpp` 只做共享时钟和两次绘制调用。模块不持有自己的计时器。`mesh_tests.cpp` 会检查确定性、随时间运动、岸线约束、中央留白和落花高度范围。

双击 `场景工程_美术重制/演示环境动态.cmd` 可进入独立演示镜头。该模式保留水面、岸线、桃树和小舟，隐藏两个人物，便于单独观察落花、水面漂移、动态波光与涟漪；空格和 R 的控制与完整场景一致。也可直接运行 `bin/LuoshenScene.exe --environment-demo`。

## 性能控制

总数固定为 62 片，每片复用三种已有低面数 OBJ 和已上传纹理，不在帧循环中分配 GPU 资源。姿态计算只包含常数次三角函数和距离判断，适合当前 OpenGL 2.1 兼容渲染路径。
