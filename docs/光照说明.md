## 这一轮改了什么

上一轮在水面上后画亮环和暗环。这一轮把那些环删掉。水面自己在动。

**水面。** 顶点按 `sin(x * 0.55 + anim * 0.7)` 和 `sin(z * 0.72 - anim * 0.5)` 上下移，幅度大约 0.05 和 0.032。法线跟着同一套相位滚动，颜色在 `(0.22, 0.36, 0.42)` 和 `(0.42, 0.52, 0.58)` 之间轻轻起伏。`anim` 用 `sceneTime`，它为 0 时用 `cloudParams.x`。暖斑仍在这块动着的水上，中心大约 `(0.4, -2.2)`，再被波形带偏，最多混入 0.7 的 `(0.94, 0.62, 0.40)`。

**山、人、地。** 山的环境光 `(0.42, 0.46, 0.50)`，主光 `(0.52, 0.44, 0.34)`。地面环境光 `(0.44, 0.40, 0.36)`，主光 `(0.58, 0.48, 0.36)`。人物环境光 `(0.46, 0.42, 0.38)`，主光 `(0.50, 0.42, 0.34)`。折面仍受光，比上一轮柔。墨发仍走暗的一支，大约 `(13, 8, 5)`。

**雾。** 只在远处的蓝灰低处。`worldHeight` 从 0.4 到 3.2，最多混入 0.16 的 `(0.68, 0.76, 0.80)`。峰顶不铺。空气上限仍是 0.02。主视图山峰大约 `(117, 144, 146)`。

**太阳。** 没改。下切仍在，圆盘大约 `(252, 220, 182)`，切边下面是桃杏天空，再下面才是山。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 顶点振幅 0.05 和 0.032 | 水面起伏，不是画上去的圆 |
| 暖斑混入 0.7 | 暖色留在动着的水上 |
| 谷雾最多 0.16 | 轻雾，山不发白 |
| 山主光 `(0.52, 0.44, 0.34)` | 黄昏里仍能看出受光 |
| 切边太阳和墨发未改 | 太阳浅桃，头发暗 |
