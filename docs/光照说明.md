# 光照说明（第七轮，未完成）

只改 `场景工程_美术重制/graphics_support.h` 和 `shadow_map.h`。人物位置、`main.cpp` 里的天空圆盘和光源上传都没动。目标仍是参考图：地平线一带是桃，往上收到杏色，淡太阳露在云外，云只有几朵而且是整朵的，远山蓝灰、山脚有雾，人物是暖的，水面保持蓝灰。

## 这一轮改了什么

天色不再停在主程序的冷蓝顶上。云改成两朵固定在世界方向上的软团，太阳圆盘从洞里露出来。人物的暖光收了一档，山脚的雾加宽了一点，峰顶仍是蓝灰。

**太阳位置没变。** 主程序仍上传 `(-12, 16, 9)`，着色器沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`。阴影相机看向 `(-4.2, 0.5, -2.8)`。天空圆盘仍在 `main.cpp`，方向是 `normalize(-0.15, 0.05, -1)`。

**天上的杏色。** 云这一趟在几何之前画，只盖住没有物体的天。视线高于地平线后，用 `smoothstep(0.02, 0.2, rd.y)` 乘 0.88，把主程序的蓝顶盖成杏色。靠近地平线是 `(0.95, 0.78, 0.62)`，再高一点是 `(0.97, 0.83, 0.70)`。太阳方向夹角在 0.05 到 0.18 弧度之间把这层挖空，圆盘本身还是主程序画的淡桃黄，云盖不上去。

**两朵云。** 不用 `atan`，所以没有竖缝。主视线看 `-Z` 时，云写在 `rd.xy` 上：中心大约 `(-0.37, 0.22)` 和 `(0.43, 0.22)`，高斯系数 85 和 100。转到侧面时用同一朵云在 `rd.yz` 上的投影，按 `rd.x²` 和 `rd.z²` 混合，转相机时云留在世界方向上，不粘在屏幕上。`smoothstep(0.25, 0.70)` 收成软边，颜色 `(0.99, 0.94, 0.88)`，透明度最多和杏色层里较大的那个。主视图里是左上一朵、右上一朵，中间和太阳是空的。

**人物和石头。** 环境光 `(0.26, 0.20, 0.18)`，主光从 `(0.68, 0.40, 0.18)` 收到 `(0.58, 0.36, 0.20)`。正对光大约是 `(0.84, 0.56, 0.38)`，还是夕阳，裙子不再那么橙。漫反射仍是 75% 的 `N·L` 加上 25% 的 `smoothstep(0.08, 0.82)`。补光 `(0.04, 0.05, 0.07)`，朝上 `(0.08, 0.045, 0.02)`，轮廓 `(0.10, 0.055, 0.03)`。影子里留 55% 直射，暗部大约 `(0.58, 0.40, 0.29)`。

**水面。** 本体仍是蓝灰：`(0.18, 0.32, 0.38)` 混到 `(0.40, 0.54, 0.60)`，光照是冷的 `(0.64, 0.72, 0.76)`，不乘暖主光。日影带宽度 0.07，只加 `(0.18, 0.11, 0.06)`。人物倒影只混 0.07 的 `(0.84, 0.70, 0.58)`。

**远山和雾。** 山体冷色 `(0.60, 0.66, 0.74)`，远处雾上限 0.16、雾色 `(0.46, 0.54, 0.60)`。山脚另有一层：世界高度中心 1.1、宽度 2.05，再乘一点噪声，最多混入 0.62 的 `(0.70, 0.78, 0.84)`。高度到 6 以上这层几乎没有，峰顶保持蓝灰，不会铺成雪。

**阴影。** `visibility = 0.55 + 0.45 * 四次采样平均`。采样大约 8 个纹素宽。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。范围仍是正交 ±13，近 0.2、远 64。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 太阳 `(-12, 5.5, 9)`，下移 `-10.5` | 和阴影相机是同一个点 |
| 杏色层 `smoothstep(0.02, 0.2)` × 0.88，太阳洞 0.05–0.18 | 天从桃收到杏，圆盘不被盖住 |
| 两朵云的 `rd.xy` 中心 `(-0.37, 0.22)`、`(0.43, 0.22)` | 整朵、没有竖缝，离开太阳 |
| 主光 `(0.58, 0.36, 0.20)` | 人物暖，但不是霓虹橙 |
| 山雾中心 1.1，宽度 2.05，最多 0.62 | 雾在山脚，峰顶仍是蓝灰 |
