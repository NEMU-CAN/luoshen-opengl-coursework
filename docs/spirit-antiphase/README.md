# 神光离合：暖冷反相改造

在当前 HEAD `ef95246` 上，把上一版"单路青白补光 + 正弦调亮度"改成"两路反相 + 已有光重新分配"。只改 `graphics_support.h` 与 `main.cpp` 两个文件，未动模型、材质、镜头、主光与布局。

## 改了什么

- 暖光与冷光各 0.05 基准，反相各走 ±15%：`warm = 0.05(1+0.15·sin)`、`cool = 0.05(1-0.15·sin)`，周期 5 秒。这是任务要求的"青白辅助光源"本体。
- "离合"由**重新分配已有光**承担：`lit *= 1 + 0.055·sin·(2·keySide − 1)`。亮面在阳相提亮、阴相回落，背光面反向，零点相位时系数恰为 1，所以不会给画面加总光量。
- 冷光以 `goddessDraw` 之外的 0.34 权重、约 2.5 单位半径衰减照到脚边水面与近岸岩石，使她不再像贴纸；远山、天空在半径外，实测差异为 0。
- 披帛相位领先神光 0.7 秒（`spiritTime + .7`），衣先动、光随后。

## 已知不足
