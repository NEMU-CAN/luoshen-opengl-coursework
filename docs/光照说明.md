# 光照说明（第八轮，未完成）

只改 `场景工程_美术重制/graphics_support.h` 和 `shadow_map.h`。人物位置、`main.cpp` 里的天空圆盘和光源上传都没动。目标仍是参考图：太阳旁边是桃橙色光晕，其余是杏色，不要灰，也不要在太阳边上露出蓝天。淡太阳露在云外，云最多两朵，远山蓝灰、雾只在山脚，人物是暖的，水面保持蓝灰。

## 这一轮改了什么

上一轮为了躲开太阳，把杏色层乘了 `sunClear`。那个洞有 0.18 弧度，洞里露出来的是主程序从地平线桃到天顶蓝的渐变，所以太阳周围发蓝，整片天也偏灰。现在天空颜色不再挖洞，只在圆盘中心留一个很小的口。云仍然乘 `sunClear`，不盖住太阳。远处的灰雾也收短了，雾还是只加在山脚。

**太阳位置没变。** 主程序仍上传 `(-12, 16, 9)`，着色器沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`。阴影相机看向 `(-4.2, 0.5, -2.8)`。天空圆盘仍在 `main.cpp`，方向是 `normalize(-0.15, 0.05, -1)`。

**太阳旁边的桃橙。** 云这一趟在几何之前画，只盖住没有物体的天。天空底色从 `(0.98, 0.66, 0.40)` 收到 `(0.95, 0.58, 0.38)`。离太阳越近，越混向 `(0.99, 0.46, 0.24)`，光晕宽度大约 0.18 弧度。透明度 0.97，蓝天透不过来。只有夹角 `smoothstep(0.012, 0.04)` 以内把透明度收掉，主程序的淡太阳圆盘还露在中间。

**两朵云。** 不用 `atan`，所以没有竖缝。主视线看 `-Z` 时，云写在 `rd.xy` 上：中心大约 `(-0.37, 0.22)` 和 `(0.43, 0.22)`，高斯系数 85 和 100。转到侧面时用同一朵云在 `rd.yz` 上的投影，按 `rd.x²` 和 `rd.z²` 混合，转相机时云留在世界方向上，不粘在屏幕上。`smoothstep(0.25, 0.70)` 收成软边，再乘 `smoothstep(0.10, 0.24)` 的太阳距离，所以云不进光晕。颜色 `(1.0, 0.88, 0.74)`，混进天空的比例最多 0.70。主视图里是左上一朵、右上一朵。

**人物和石头。** 环境光 `(0.26, 0.20, 0.18)`，主光从 `(0.68, 0.40, 0.18)` 收到 `(0.58, 0.36, 0.20)`。正对光大约是 `(0.84, 0.56, 0.38)`，还是夕阳，裙子不再那么橙。漫反射仍是 75% 的 `N·L` 加上 25% 的 `smoothstep(0.08, 0.82)`。补光 `(0.04, 0.05, 0.07)`，朝上 `(0.08, 0.045, 0.02)`，轮廓 `(0.10, 0.055, 0.03)`。影子里留 55% 直射，暗部大约 `(0.58, 0.40, 0.29)`。

**水面。** 本体仍是蓝灰：`(0.18, 0.32, 0.38)` 混到 `(0.40, 0.54, 0.60)`，光照是冷的 `(0.64, 0.72, 0.76)`，不乘暖主光。日影带宽度 0.07，只加 `(0.18, 0.11, 0.06)`。人物倒影只混 0.07 的 `(0.84, 0.70, 0.58)`。

**远山和雾。** 山体冷色 `(0.60, 0.66, 0.74)`，远处雾上限 0.16、雾色 `(0.46, 0.54, 0.60)`。山脚另有一层：世界高度中心 1.1、宽度 2.05，再乘一点噪声，最多混入 0.62 的 `(0.70, 0.78, 0.84)`。高度到 6 以上这层几乎没有，峰顶保持蓝灰。人物和地面上的那层灰雾从上限 0.24 收到 0.12，雾色改成 `(0.86, 0.72, 0.58)`，近处不再发灰。水面雾色仍是 `(0.60, 0.70, 0.76)`。

**阴影。** `visibility = 0.55 + 0.45 * 四次采样平均`。采样大约 8 个纹素宽。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。范围仍是正交 ±13，近 0.2、远 64。
