# 光照说明（第十四轮，未完成）

只改 `场景工程_美术重制/graphics_support.h`。`shadow_map.h` 没动。天仍是饱和的桃杏。太阳是浅桃色圆盘，下沿自己切平，和山脊之间留着一段天空，山没有挡住它。

## 这一轮改了什么

上一轮圆盘下移太多，只剩一条埋在山脊里的缝。山上的雾按世界高度直接混进山体，看起来穿进了峰面。这一轮把圆盘抬高、放大，并把那层面上的雾去掉。谷地的雾改画在天空那一层，山体会把它挡住。

**灯光位置。** 主程序仍上传 `(-12, 16, 9)`，着色器沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`，阴影相机看向 `(-4.2, 0.5, -2.8)`。天上的圆盘用 `normalize(-0.15, 0.055, -1)`，整颗在山脊上方。

**一条黄昏天。** 视线高度 `smoothstep(0.0, 0.42, rd.y)` 从 `(0.98, 0.72, 0.54)` 混到 `(0.95, 0.64, 0.48)`。透明度是 1。主视图天空大约 `(245, 170, 127)`。靠近地平线、`rd.y` 低于 0.05 的地方混入 `(0.68, 0.76, 0.82)`，这层在山的后面。圆盘硬边 `smoothstep(0.036, 0.040)`，颜色 `(1.0, 0.93, 0.80)`。下沿用 `step(below, 0.012)` 切平，切掉的是圆盘自己，不是山挡住的。主视图里切边大约在 y=306，下面还有 54 个像素的桃杏天空，山影从 y=361 才开始。

**水面。** 本体是蓝灰：`(0.24, 0.42, 0.50)` 混到 `(0.52, 0.66, 0.74)`，光照是冷的 `(0.82, 0.88, 0.92)`。暖斑中心在世界坐标 `(-1.6, -4.7)`，横向 1.6、纵向 0.95，最多混入 0.82 的 `(0.96, 0.60, 0.38)`。再往近处的水不吃这层。人物倒影只混 0.07 的 `(0.84, 0.70, 0.58)`。

**远山和雾。** 山体光照 `(0.78, 0.84, 0.90)`。不再按高度把雾色混进山的表面。远处空气上限 0.05。谷地和山脚的雾在天空层，山画在它前面。

**人物和石头。** 环境光 `(0.36, 0.28, 0.24)`，主光 `(0.66, 0.44, 0.26)`。正对光大约是 `(1.02, 0.72, 0.50)`。漫反射是 75% 的 `N·L` 加上 25% 的 `smoothstep(0.08, 0.82)`。补光 `(0.04, 0.05, 0.07)`，朝上 `(0.08, 0.045, 0.02)`，轮廓 `(0.10, 0.055, 0.03)`。影子里留 55% 直射。

**阴影。** `visibility = 0.55 + 0.45 * 四次采样平均`。采样大约 8 个纹素宽。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。范围仍是正交 ±13，近 0.2、远 64。
