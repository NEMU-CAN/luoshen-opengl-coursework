# 光照说明（第一轮，未完成）

这一轮只改了 `场景工程_美术重制/graphics_support.h` 和 `shadow_map.h`。人物位置没动。主程序里的光源坐标也没改，天空颜色仍在 `main.cpp` 的 `sky()` 里。

## 原先的问题

主光在世界坐标 `(-12, 16, 9)`，对着人物大约是 48° 的高光，更接近下午，不像夕阳。环境光偏冷蓝 `(0.31, 0.36, 0.39)`，主光再叠加 `(0.88, 0.70, 0.49)`，正对光的一面红通道会超过 1，肤色容易发白。补光是冷色 `(0.12, 0.19, 0.23)`。

水面主体是青绿色 `(0.075, 0.235, 0.275)`，掠射角又混进灰绿，和天空地平线的桃色 `(0.90, 0.79, 0.65)` 不是一家。雾从距离 8 就开始，浓度 0.022，最多能盖住 86% 的颜色，人和石头容易糊掉。

阴影最暗只留 18% 的直射光（`0.18 + 0.82 * 采样`）。折面岩岸的明暗会被压得很死，站在影子里的人也会发黑。远山另用了一套跟着相机的冷光，和夕阳脱节。

## 这次改了什么

**光的方向。** 主程序仍然上传 `(-12, 16, 9)`。片元着色器只沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`。相机转动时这个太阳仍钉在世界上。对着岩岸和两个人（大约 `(-4.2, 0.5, -2.8)`），仰角大约 20°。阴影相机用同一个点，看向 `(-4.2, 0.5, -2.8)`，这样高光和影子是同一轮太阳。

**颜色。** 环境光改为暖褐色 `(0.22, 0.15, 0.11)`。主光改为 `(0.74, 0.45, 0.20)`。正对光时两者相加大约是 `(0.96, 0.60, 0.31)`，红通道留在 1 以下，肤色不会爆掉。补光减弱为 `(0.06, 0.04, 0.03)`，方向仍是眼空间里的 `(-0.15, 0.65, 0.55)`，只负责把暗部轻轻托住。

**高光（Phong 指数）。** 皮肤和衣服、石头共用默认材质：指数 42（原来 35），强度 0.018（原来 0.035），高光更小也更弱。头发指数 56、强度 0.08。水面指数 96、强度 0.10。高光颜色统一为 `(1.0, 0.78, 0.46)`。

**水面。** 深水 `(0.13, 0.09, 0.07)`，亮纹 `(0.58, 0.36, 0.20)`，按 0.40 混合。掠射角混入 `(0.88, 0.72, 0.52)`，靠近天空地平线。水波公式没改。倒影偏色改为 `(0.70, 0.50, 0.34)`，混合 0.32。

**雾。** 10 个单位以内几乎没有雾，人物在主镜头里保持清楚。更远的浓度：景物 0.007，远山 0.012。近地薄雾系数 0.05。雾色陆地 `(0.86, 0.72, 0.56)`，水面 `(0.78, 0.62, 0.46)`。混合上限 0.38，不再用大雾盖住模型。远山改用同一轮主光，距离感交给雾。

**阴影。** 最暗仍保留 46% 直射光：`visibility = 0.46 + 0.54 * 四次采样平均`。折面还能看出亮暗，人在影子里不会黑成一块。深度偏移 `max(0.0011, 0.0026 * (1 - N·L))`，绘制偏移 `glPolygonOffset(2.2, 5)`，减轻低角度太阳的阴影噪点。阴影范围改为正交 ±13，近 0.2、远 64，把岩岸和两个人包在 2048 的贴图中间。

## 哪些数最要紧

| 数 | 作用 |
|---|---|
| 太阳 `(-12, 5.5, 9)`，下移量 `-10.5` | 必须和 `shadow_map.h` 里的光源一致 |
| 主光 `(0.74, 0.45, 0.20)` + 环境光 `(0.22, 0.15, 0.11)` | 暖，且皮肤正对光时不超过 1 |
| 默认高光指数 42、强度 0.018 | 皮肤不要一块白斑 |
| 雾：起点 10，浓度 0.007，上限 0.38 | 人清楚，远处仍有空气 |
| 阴影下限 0.46 | 岩岸有影子，人物不被压黑 |

水面波纹、花瓣和人物位置这一轮都没动。天空圆盘仍是主程序里接近地平线的方向，和这轮主光的水平方位还不完全重合，下一步若要改天空，需要动 `main.cpp`，得和布局负责人说好。
