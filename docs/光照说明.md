# 光照说明（第十一轮，未完成）

只改 `场景工程_美术重制/graphics_support.h`。`shadow_map.h` 这一轮没动。没有云。太阳是浅桃色圆盘，不是白的。水面仍是蓝灰，中间有一条暖的日影。人物、山和水都比上一轮亮，仍是黄昏。

## 这一轮改了什么

上一轮圆盘是 `(1.0, 0.96, 0.88)`，发白。水面的暖带乘在冷光之前，几乎看不见。这一轮把圆盘改成浅桃，日影加在水面光照之后，并把人物、山、水的底光抬高。

**太阳位置没变。** 主程序仍上传 `(-12, 16, 9)`，着色器沿世界上方向下移 10.5，得到 `(-12, 5.5, 9)`。阴影相机看向 `(-4.2, 0.5, -2.8)`。天空圆盘的方向仍是 `normalize(-0.15, 0.05, -1)`，着色器用同一个方向把淡太阳画进渐变。

**一条黄昏天。** 视线高度 `smoothstep(-0.02, 0.55, rd.y)` 从 `(0.98, 0.64, 0.46)` 混到 `(0.96, 0.71, 0.55)`。透明度是 1，蓝天透不过来。圆盘中心在夹角 0.012 以内是 `(1.0, 0.84, 0.66)`，到 0.030 收边。主视图里圆盘大约是 `(255, 214, 168)`，旁边的天大约是 `(249, 167, 122)`。没有云。

**人物和石头。** 环境光 `(0.36, 0.28, 0.24)`，主光 `(0.66, 0.44, 0.26)`。正对光大约是 `(1.02, 0.72, 0.50)`。漫反射是 75% 的 `N·L` 加上 25% 的 `smoothstep(0.08, 0.82)`。补光 `(0.04, 0.05, 0.07)`，朝上 `(0.08, 0.045, 0.02)`，轮廓 `(0.10, 0.055, 0.03)`。影子里留 55% 直射。

**水面。** 本体是蓝灰：`(0.24, 0.42, 0.50)` 混到 `(0.52, 0.66, 0.74)`，光照是冷的 `(0.82, 0.88, 0.92)`，不乘暖主光。日影在光照之后再混：世界坐标 `x = -0.9 + 0.15z` 为中心，宽度约 `0.9`，最多混入 0.58 的 `(0.90, 0.55, 0.34)`。带子以外仍是蓝灰。人物倒影只混 0.07 的 `(0.84, 0.70, 0.58)`。

**远山和雾。** 山体光照 `(0.78, 0.84, 0.90)`。远处空气从 22 以外才开始，山的上限 0.08。山脚薄雾中心高度 0.6、宽度 0.9，最多混入 0.22 的 `(0.58, 0.66, 0.72)`。峰顶不白。

**阴影。** `visibility = 0.55 + 0.45 * 四次采样平均`。采样大约 8 个纹素宽。深度偏移 `max(0.0022, 0.0052 * (1 - N·L))`，绘制偏移 `glPolygonOffset(3.4, 9)`。范围仍是正交 ±13，近 0.2、远 64。
