# 洛神颈部与耳坠修复

本次从 `E:/Downloads/luoshen.blend` 和同目录原始 OBJ 压缩包起步。用户收回此前的头脸、头发重做要求，较早的预览已弃用。

- 将原颈部前后挤出的台阶形轮廓改为连续截面的短颈。下缘藏入原衣领，上缘沿原下颌进入发下，使用原有皮肤材质。第二轮检查后将颈底向领内收回，避免颈部挡住红领线。
- 近侧链和坠作为一组平移至已有耳垂。原件只有一侧单独建模的耳朵，远侧链和坠作为一组平移至另一侧鬓发遮住的原脸侧边。每组链与坠的形状、朝向、相互位置和材质均保留。两条链的顶端均嵌入相应皮肤表面约 0.5 mm（以 Blender 单位为米计）。
- 在相同光照和机位下分别渲染并检查正面、四分之三、侧面、背面和全身。[局部三视图对照](../assets/luoshen-current/head-study/neck-ear-comparison.png)上排为原件，下排为交付版。

## 验证
